### What's New in 2.7.1!

This release adds multi-file selection and export in the file manager, configurable strategy sheets, and new image and animation export resolutions. It also makes saving, updating, plugins and telemetry safer, and fixes several bugs.

## File manager

- Select several files at once and export them together.
- Export a file straight from the file manager.
- Added a **Show in Finder/File Explorer** option.
- Search is clearer and finds more.
- On Windows, the default folder is now your Documents folder, found through the system instead of the `HOME` variable.
- A file the file manager can't read, such as a broken symlink, is skipped. It used to show an empty folder.

## Export

- Strategy sheets are now configurable.
- Image exports now use real resolutions instead of a scale. Animated exports also accept a custom resolution.
- The points exporter is more meaningful and easier to read.
- The Code tab uses the current file name. If you typed your own class name, it updates when the file name changes.

## Updates and plugins

- Turning a plugin on now asks first. It says the plugin can read, change and delete any file and use your saved GitHub sign-in.
- Bundled plugins now update, but only if you haven't edited them.
- The updater runs the `install.sh` from the release tag (`…/v2.7.1/install.sh`) instead of the one on `main`, and strips only a leading `v` from the version tag.

## Telemetry

- Telemetry keeps one connection per window. A closed window drops its connection, and a replaced connection's late close is ignored.
- Telemetry drops a line over 1 MB, checks the host and port, and gives up connecting after 10 seconds.

## **Bug Fixes:**

- The optimizer sometimes went through obstacles. It no longer does.
- History now works without deleting paths.
- Projects are saved atomically (written, then renamed), so a power failure can't lose a file.
- File names with two dots in a row, such as `Red..v2.turt`, now work.
- The timeline hover lines up correctly, and image assets can no longer be dragged by accident.
- Robot feature properties had the wrong name. They now have the right one.
- Fixed the Browser icon.
- Removed the Squared Corners interface option.
