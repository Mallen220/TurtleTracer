# What's New!

This release makes the simulation much closer to what the robot actually does on the field. It also adds experimental Kotlin support and reads the newer `.pp` format.

## Kotlin

- Added experimental Kotlin code export and import support. You can also follow a Kotlin file while you edit it, the same way as a Java file.
- Kotlin is not yet tested independently, so please report any bugs you find with it.

## Simulation accuracy

- Sharp turns now simulate the robot overshooting the path before it recovers.
- Added support for feedforward tuned values, which makes the simulation substantially more accurate.
- Telemetry now watches how the robot behaves and suggests corrections to the visualizer settings.
- Added a warning when piecewise heading angles can't be reached, with suggested fixes.
- Each path or chain can now have its own max speed. It is included in exported code.
- Bends the robot can't follow at speed are now shown running wide, with a warning and a one-click speed fix.

## Files and code export

- Added support for the updated `.pp` format. Older `.pp` files still open.
- In the desktop app, Turtle Tracer now reads your robot project. It detects your Pedro constants class, Pedro version, and command library, and uses them in exported code.

## Editing

- Snapping no longer requires the grid to be turned on. Both still use the same global grid size.
- The path chaining button is easier to find. It is now part of the onboarding tutorial, and hovering over it explains what it does.
- The path optimizer leaves paths that are already good alone instead of redrawing them for a tiny gain.

## Documentation

- Updated the documentation and made it easier to keep up to date.

## Bug Fixes

- Fixed a bug where obstacles near the start of a path were sometimes ignored when checking for collisions.
