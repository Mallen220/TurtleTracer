# What's New in 2.2.2!

BioBuzz field map support, PedroPathing 3.0.0 and TurtleTracerLib Events integration, and optimization preview fixes.

## **Visualizations & Field Rendering**

- **BioBuzz Field & Obstacles:** Updated default field map and obstacle layouts to the new BioBuzz season (2026-2027), while preserving legacy configurations as selectable presets.
- **Optimization Preview Animation:** Fixed an issue where the blue dotted optimization preview line only animated on the initial run instead of updating across every calculation iteration.
- **Default Safety Margin:** Changed default obstacle safety margin to two inches from six inches for closer path tracking and realistic robot clearance.

## **Interface & Accessibility**

- **Microsoft Store:** Fixed critical bug where program crashes on new installs. 
- **Issue Count Text:** Fixed minor bug where text said "Found Issues" when only one issue was found.

## **Architecture & Core Logic**

- **PedroPathing 3.0.0 & TurtleTracerLib Events:** Code exporter now supports TurtleTracerLib Events since PedroPathing deprecated callbacks, and updated code exporter for Pedro 3.0.0.
